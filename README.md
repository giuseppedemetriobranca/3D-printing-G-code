# 3D-printing-G-code
In questa sezione vengono pubblicati G-code per stampa 3D di diversi progetti.
ATTENZIONE: I file G-code presenti in questa repository sono configurati per hardware specifici. Stampare questi file su macchine diverse o con materiali non idonei può causare fallimenti di stampa o danni hardware. Utilizzali a tuo rischio e pericolo.
